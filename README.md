# High-Performance Agentic RAG Chatbot

A modular, production-ready conversational AI platform combining a low-latency C++ REST API backend with an intelligent Agentic Retrieval-Augmented Generation (RAG) engine.

## Team Workflow & Rules
1. **Never commit directly to `main`.**
2. Work only on your assigned branch.
3. Once your phase implementation is complete, open a **Pull Request (PR)** against `main`.
4. I will review, test, optimize, and merge your PR.

## Phases & Branch Assignments
* **Phase 1 (`phase-1-backend-api`):** C++ Backend & REST API setup (chat, file upload, health checks).
* **Phase 2 (`phase-2-auth-security`):** Authentication, RBAC, and multi-tenant data isolation.
* **Phase 3 (`phase-3-data-ingestion`):** Ingestion and parsing for PDF, CSV, Excel, and JSON formats.
* **Phase 4 (`phase-4-rag-retrieval`):** Vector database indexing, embeddings, and permission-aware retrieval.
* **Phase 5 (`phase-5-agentic-rag`):** Autonomous agent reasoning, dynamic tool selection, and query planning.
* **Phase 6 (`phase-6-llm-integration`):** LLM context assembly, prompt engineering, and response validation.
* **Phase 7 (`phase-7-testing-performance`):** Security penetration testing and ~200 ms latency optimization.
* **Phase 8 (`phase-8-chatbot-ui`):** Plug-and-play frontend UI component and REST API integration.
* **Phase 9:** System Integration, E2E Testing & Deployment .
